# Texture-Analysis-and-Feature-Detection-by-SIFT-ORB-LBP-and-GLCM
 this paper contrasts SIFT against  ORB; for the texture analysis considering the  range of objects and texture detection under  different light intensities, LBP against GLCM.  Among the most often occurring applications for  these techniques are object recognition, medical  imaging, and image categorization.
